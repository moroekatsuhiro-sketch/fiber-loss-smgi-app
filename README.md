## 区間名の自動更新

始端・遠端の盤名を変更すると、区間名を「始端 ～ 遠端」に更新します。履歴編集・複製・貼り付け・再起動後も同じ動作です。手入力した区間名は盤名を変更するまで保持し、盤名を変更した際に再生成します。どちらかの盤名を空欄にすると区間名も空欄になります。旧版の手入力固定フラグは引き継ぎません。

## 工事番号・入力日による校正値の引用

基本情報に入力日を追加しました。新規入力時は端末の今日の日付です。
同じ工事番号・入力日・ケーブル種類（SM/GI）・波長の保存履歴から、空欄の始点／終点校正値を自動引用します。「履歴から空欄の校正値を引用」でも実行できます。

- 複数候補がある場合は更新日時（未更新なら保存日時）が新しい履歴から、始点・終点それぞれの有効値を採用します。0も有効値です。
- 引用元の区間名を画面に表示します。編集中の履歴自身は引用候補から除外します。
- 手入力済みの校正値は保持します。自動引用した値は工事番号・入力日・種類を変更すると見直します。引用後に手修正した値は手入力として扱います。
- 旧履歴には入力日がないため、保存日時の端末ローカル日付を使用し「保存日から推定」と表示します。必要に応じて履歴編集で修正してください。
- 入力日を履歴・自動保存・CSV・JSON・控えに保存／表示します。

## 工事番号ごとの履歴管理

工事番号でグループ化し、見出しを押すと開閉できます。工事番号の一部や K-26001 形式で絞り込めます。更新／保存日時が新しい履歴から表示します。

「この履歴を編集」は元の履歴を上書きします。保存後・再起動後も上書きモードを維持します。

## 別の測定データへの再利用

### 同じアプリ内で複製
履歴の「新規測定に複製」を押すと、基本情報・入力日・波長別設定・校正値・測定値を新規入力へ複製します。工事番号・日付・盤名・測定値などを確認・修正して保存してください。別のIDで新しい履歴として保存し、元の履歴は残します。現在の入力がある場合は確認し、バックアップへ退避してから読み込みます。

### コピー／貼り付け
1. コピー元の履歴で「履歴をコピー」を押します。
2. コピー先のアプリの「履歴」→「履歴のコピー／貼り付け」を開きます。
3. 履歴データ欄に貼り付け、「新規測定として貼り付け」を押します。
4. 内容を確認・修正して保存します。

専用JSON形式でコピーします。自動コピーが使えない環境ではデータ欄を選択するため、Ctrl+Cまたは長押しでコピーしてください。貼り付けデータを検証し、規格値を再計算して読み込みます。不正な貼り付けデータでは現在の入力・履歴を変更しません。Excelなどへの出力には「この履歴をCSV出力」を使用できます。

履歴と入力途中のデータは端末・ブラウザのlocalStorageに保存されます。別端末への自動同期はありません。コピー／貼り付けまたはJSONバックアップで移動してください。

## 維持した仕様

- ケーブル長m直接入力を優先し、空欄の場合はレングスマークの差を使用します。
- 測定値・校正値・規格値は小数第3位以下を切り捨て、小数第2位まで表示します。
- 校正値は記録用です。規格値・測定値には加減算しません。
- SM/GIや異なる波長間では校正値を流用しません。
- 入力全体の自動保存と起動時復元、最大2世代の軽量バックアップを維持します。
- PWA更新は3分ごとに確認し、更新ボタンで適用します。

## ファイルと検証

- index.html / style.css：画面
- app.js：計算・測定・保存・PWA
- history.js：入力日・校正値引用・履歴コピー／貼り付け
- service-worker.js：history.jsを含む新バージョンのキャッシュ
- test-history.cjs：PlaywrightとMicrosoft Edgeによるブラウザ回帰テスト

PlaywrightとMicrosoft Edgeを用意し、`node test-history.cjs`で実行します。独立したブラウザコンテキストと試験用データを使います。工事番号・入力日・種類・波長の一致、ゼロ値、手入力保護、再起動、上書きモード、複製、コピー／貼り付け、不正データ、絞り込み、旧履歴、CSV列の整合性を検証します。
